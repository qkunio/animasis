## 字幕与结尾

- 字幕不再是概述式短句，也不是打字机逐字出现：每一句都直接取旁白原文，按标点切成 1–2 个短句，
  用该句的实测 TTS 时长按字数比例分配时间窗；字幕与语音同起同落，不增删字。
- 冷开场第 1 句由画面中的大字承担，不重复叠底字幕；第 2 句起显示底部字幕。
- 结尾只有两行：`一桶石油，半个现代生活` / `@像素万物局`，没有总结条目和片尾署名。

## 数字与口径

- 1 桶 = 42 美制加仑 ≈ **159 升**。
- 美国炼厂 2023 年产品收率（EIA 口径，体积占比）：汽油约 **46%**、馏分油（柴油 / 取暖油）约 **30%**、航空煤油约 **11%**，其余为液化气、沥青、润滑油、石油焦等。加工增益会让成品总体积略大于原油体积，所以片中写“约 45 加仑成品油”。
- 常压分馏的 6 个馏分：石油气（<40°C）、汽油（约 40–180°C）、煤油（约 180–250°C）、柴油（约 250–350°C）、重油（>350°C）、塔底渣油（进一步加工得到润滑油、石蜡、沥青）。
- “上千种产品”指石油化工深加工后的产品种类；直接分馏得到的是 6 大馏分，不是最终产品。

## 本片新增的引擎能力

- `animasis/petro.py`：石油专题叠加层，全部为世界坐标、可被相机推拉：
  - `pumpjack`：动画抽油机（游梁、驴头、配重、曲柄、电机）。
  - `barrel`：带箍和液滴标签的油桶。
  - `droplet`：原油液滴。
  - `molecule`：链烃 / 苯环 / 聚合物骨架，可逐段生长，带 C/H 原子点。
  - `column`：分馏塔（加热炉、塔板、上升油气、回流液滴、6 个侧线、温度标尺、流动光点）。
  - `cutbar`：带逐段生长动画的堆叠条形图。
  - `product`：货架产品图标 + 标签，整体随镜头缩放。
- 新背景：`oilfield`（落日油田、远处抽油机与井架）、`shelf`（深色产品墙 + 两层木货架）。
- `icons.py` 新增 12 个产品图标：塑料瓶、涤纶衣服、轮胎、手机壳、油漆、洗涤剂、阿司匹林、口红、沥青路、口罩、电缆、保鲜膜。
- 冷开场动效：`droplet` 的 `y0`/`fall` 坠落、`splash` 溅射、逐字大字，以及一镜到底的跟拍/缓推；`kinetic` 弹出大字仍保留给其他片子。
- 相机：45 个镜位；冷开场用一镜到底的跟拍和缓推抓人，正片用 37 个镜位完成“油田 → 分子 → 分馏塔 → 产量图 → 裂解 → 产品墙 → 油田”的叙事。

## 重新渲染

```bash
cd animasis
# 1) 重新生成 YAML（改了文案、几何或镜头后）
python demos/petroleum_gen.py
# 2) 渲染 + 旁白（需要联网调用 edge-tts；已生成的句子会走缓存）
python -m animasis narrate demos/petroleum.yaml -o demos/output/petroleum.mp4
# 3) 只看镜头表
python -m animasis shots demos/petroleum.yaml --markdown
```

> Windows 上如果 `ffmpeg` 不带 libx264，可把带 libx264 的 ffmpeg 放到 PATH 最前面（例如 `imageio-ffmpeg` 自带的二进制）。
