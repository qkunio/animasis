## 本片新增的引擎能力

- 背景：`space`（星空、淡星云）和 `blueprint`（蓝图网格，用于示意图）。
- 叠加层 `animasis/space.py`，都是世界坐标，镜头可以推拉：
  - `planet`：球面投影的自转地球，有陆地、云、冰盖、明暗交界和夜侧城市灯光。
  - `orbit`：虚线轨道，可以分前半圈和后半圈，配合地球做遮挡。
  - `satellite`：太阳翼卫星，可以定点并上下浮动，也可以沿 `orbit` 飞行，飞到远侧时被地球挡住；`signal` 会画出向目标扩散的信号波。
  - `range`：逐渐画出的测距虚线，上面有信号脉冲。
  - `ring`：逐渐展开的距离圆，`fuzz` / `sharpen` 用来表现时钟误差。
  - `pin`：落下并发出脉冲的定位针。
  - `phone`：地图 App，先显示搜索中，`lock` 之后出现蓝点，状态栏显示卫星数。
  - `glyph`：小图形，包括 car、scooter、bike、tripod、clock、plane、ship。
- 文本：`fmt` + `from` / `to` / `count` 可以显示滚动计数，例如距离和时间读数。
- 相机：镜头可以对准带 `id` 的卫星；对准轨道上的卫星时会实时跟拍。`space: world` 的标签如果不在当前镜头里，会自动隐藏，不会挤在画面边缘。
- 人物：新增 `phone` 道具图标和看手机的 `phone` 姿势。
